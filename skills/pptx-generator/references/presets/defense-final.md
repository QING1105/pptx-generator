> 进入内容询问之前，先确认视觉风格。后续设计表生成时将此信息填入表头。

- **追问**：
  - 色系风格选哪个？（S1-S4 瑞士 / M1-M5 杂志 / O1-O18 商务，可发 preview.html 预览链接）

  - 英文字体确认？（默认 Arial，可选 Helvetica / Georgia）
  - **汇报语言确认？**
    - 中文汇报 → slide 文本全部中文（论文题目保留英文）
    - 英文汇报 → slide 文本全部英文

  - **幻灯片尺寸确认？**
    - PowerPoint 宽屏 16:9：13.33" × 7.5"（33.87 × 19.05 cm）← 默认推荐
    - WPS 宽屏 16:9：13.33" × 7.5"（同上）
    - 标准 4:3：10" × 7.5"（25.4 × 19.05 cm）
    - 自定义：______
  - 是否需要章节分隔页？封面是否需要英文题名页？

> **画布适配约束**：风格包坐标不是等比缩放——每个支持的尺寸（13.33"×7.5" / 10"×7.5" / 10"×5.625"）都要有独立的 x/y/w/h/fontSize 坐标表。视觉节奏（留白、字间距、图文密度）按尺寸独立调校，不靠 `scale_factor`。

## 一、苏格拉底引导清单

### 板块：封面

- **必备要素**：论文题目（中英文）、学生姓名、导师姓名、学院/年级/学位类型、日期
- **常见遗漏**：英文题目忘写或格式不一致
- **追问**：
  - 中文题目定稿了吗？有没有副标题？
  - 英文题目是否和中文对应?
  - 导师名字有没有行政职务头衔需要加？

### 板块：目录

- **必备要素**：章节编号 + 章节名，5-6 章为佳
- **常见遗漏**：目录和实际页面标题不一致；章节编号体系混乱
- **追问**：
  - 这五个章节名和你论文的章节目录一致吗？
  - 有没有哪章在论文里有但答辩 PPT 里不讲的？

### 板块：研究背景

- **必备要素**：现有的痛点/问题( 临床问题 )→ 现有方案局限 → 实验提出的基础 → 引出本课题的必要性，每页一个独立论点，层层递进
- **常见遗漏**：背景太长冲淡核心问题；文献引用缺失或不全；只有文字堆砌没有层级递进
- **追问**：
  - 第一页"现有痛点"——这个痛点的数据来源是什么？流行病学统计数据?
  - 现有方案的局限性——现有方案局限性的原因是？为什么现有方案不适用？
  - 怎么做改进——改进的方法/核心技术在你的领域里别人用过吗？还是新应用？
  - 请检查整体是否具备是什么/为什么/怎么做/可行性分析?
  - 每页底部的参考文献引全了吗？
  - 每页配了几张图？哪些页是纯文字、哪些是图文混排？（这决定用单列文字版式还是图文双列版式）

### 板块：研究内容

- **必备要素**：关键科学问题一句话凝练 → 拆分为 2-3 个具体研究内容方向 → 技术路线图，每个子方向之间的逻辑关系标清楚
- **常见遗漏**：科学问题写成了研究目标（"我要做什么"vs"我要回答什么"）；路线图分部和具体研究内容方向不对应
- **追问**：
  - 关键科学问题如果用一句话说，是什么？(问题为什么关键?为什么要用这个方法解决?思考清楚后总结成用什么方法解决什么关键问题)
  - 子方向之间是递进还是并行？有没有标注先后/依赖关系？
  - 梳理后技术路线图是现成的还是要重新画？如果重画，层次是？
  - 除路线图外，这部分还有几张图？每个子方向是否需要单独配示意图？

### 板块：研究结果（分三部分）

- **必备要素**：每部分含若干数据页 + 一页小结。每个数据页有 Fig 编号、子图标注 a/b/c/d、关键结论一句话。小结页 3-4 条 bullet + 回顾图。三部分之间由章节分隔页断开。
- **常见遗漏**：图表没有 Fig 编号；只展示数据不给结论；小结纯文字不回顾关键图；三部分之间缺过渡逻辑，听众不知道"刚才那部分证明了什么、接下来要证明什么"；部分之间的逻辑链断裂（表征→体外→体内的递进关系不明确）

#### 追问（通用，三部分都适用）

- 你研究内容的逻辑顺序是什么？PPT 的数据排列是否严格跟着这个顺序走？
- 每个数据页的 n 数和统计方法是什么？p 值标了吗?bar值有没有标注?
- 阳性对照和阴性对照全不全？对照组有没有临床/领域公认的参照意义？
- 每部分小结能不能用一句话和前一部分串起来——"第一部分证明了 X，所以第二部分要验证 Y"？
- 每部分共有几张图？每张图单独放一页还是需要合并（如 a/b/c/d 四图一页）？每页图的数量直接影响分栏版式——1 张用全幅、2 张用双列、3-4 张用四格。

#### 追问（第一部分：体系构建与表征）

> 适用于材料、药物、模型、探针、基因编辑等任何需要"先搭出来再验证"的研究。

- **必备要素**：构建/制备流程 → 结构/形貌/理化性质表征 → 关键参数对比 → 证明"东西做出来了且符合预期"
- **常见遗漏**：只展示表征结果不总结"这个结果意味着什么"；不同批次/组间的一致性数据缺失；表征维度不完整（比如只做了形貌，没做关键的理化性能）
- **追问**：
  - 制备流程的核心参数有哪些？是否已全部确认？有没有关键步骤的工艺优化数据需要展示？
  - 表征维度是否覆盖了该体系的核心指标？（形态/结构/粒径/电位/载药量/包封率/纯度/活性……根据体系类型逐项核对）
  - 是否设了对照组或不同配比/条件的比较组？组间差异是否有统计学意义？
  - 表征图和制备流程图上的标尺、箭头、标注是否完整？
  - 小结：你的东西"做出来了吗"？哪几个数据最能证明它符合设计预期？

#### 追问（第二部分：体外实验）

> 适用于细胞、分子、生化、微生物等体外层面的机制或效应验证。

- **必备要素**：安全性/毒性 → 靶向/摄取/定位（如有）→ 效应验证（增殖/凋亡/分化/迁移/分泌……）→ 机制探究（信号通路/基因表达/蛋白互作……）→ 小结
- **常见遗漏**：体外实验和第一部分之间逻辑跳跃（材料表征完了直接跳到细胞实验，中间缺"为什么要做这些细胞实验"的桥）；效应验证和机制探究混在一起分不清层次；时间点和浓度梯度不完整；只做现象不做机制
- **追问**：
  - 体外实验的排列逻辑是什么？安全性→效应→机制，还是按细胞类型/实验类型分组？
  - 安全性/毒性——做了几个时间点？几个浓度梯度？用什么方法（MTT/CCK8/LDH/活死染色……）？和现有方案对比了吗？
  - 靶向/摄取/定位——有没有证明你的体系到达了目标位置（细胞摄取/亚细胞定位/组织分布）？
  - 效应验证——你声称的生物学效应（促增殖/抑凋亡/诱导分化/抑制迁移……）分别用了什么实验来证明？每个实验有独立 Fig 吗？
  - 机制探究——做了哪些层面的机制？（mRNA/蛋白/磷酸化/信号通路阻断回复实验……）如果没做机制，有没有说明原因？
  - 小结：从体外实验结果中，你能得出什么结论？这个结论能不能支撑你推进到体内实验？

#### 追问（第三部分：体内功能验证）

> 适用于动物实验、临床样本、在体影像、组织学等最终功能验证。

- **必备要素**：动物模型构建与分组 → 在体评价（影像/行为/生理指标/生存曲线……）→ 组织学/病理学终点分析 → 安全性/毒副作用 → 小结（完整证据链闭环）
- **常见遗漏**：动物模型构建参数不完整（种属/性别/数量/造模方法/成模标准）；只放代表性图片不做定量统计；组织学只有一张典型图没有多组对比或多视野统计；体内安全性数据缺失（体重/脏器系数/血常规/生化）；终点指标单一，没有多维度互证
- **追问**：
  - 动物模型——种属、性别、月龄、每组 n 数、造模方法和成模标准是什么？n 数是否满足统计学要求？
  - 分组设计——几组？每组分别代表什么条件？（假手术/模型/阳性药/实验组低中高剂量……）有没有各组基线数据的可比性证明？
  - 在体评价——用了哪些手段？（活体成像/Micro-CT/MRI/超声/行为学评分/生存分析……）是定性图片还是定量数据？数据采集时间点是如何确定的？
  - 组织学终点——取材部位、染色方法、观察指标是什么？有没有多组并列对比的排版？有没有做半定量/定量评分（如免疫组化评分、新骨面积比、纤维化面积比、TUNEL 阳性率……）？
  - 安全性/毒副作用——有没有体重曲线、脏器系数、血常规、肝肾功等系统毒性数据？如果是药物/材料，体内降解/代谢/分布做了吗？
  - 小结——三段论能不能闭环：第一部分证明"做出来了"→ 第二部分证明"体外有效且安全"→ 第三部分证明"体内确实有效"→ 整体回答了你最初提出的关键科学问题吗？
  - 如果体内实验没做或部分缺失——是因为课题阶段限制还是方法学瓶颈？有没有替代方案（如类器官、器官芯片、离体组织培养）？这部分缺失是否会影响答辩评定？需不需要在创新与不足中明确说明？

### 板块：创新与不足

- **必备要素**：2-3 条创新点 + 2-3 条局限性，每条不超过两行
- **常见遗漏**：创新点和研究内容完全重复；局限性写得像偷懒而不是方法学边界
- **追问**：
  - 创新点如果只留两条，哪两条是对关键科学问题有改善的？
  - 局限性里有没有实验条件限制（模型/观察时长/样本量）？还是方法学固有局限？
  - 创新和局限能不能相互呼应？（比如"首次用于 X"↔"但仅在 Y 模型验证"）

### 板块：致谢与成果

- **必备要素**：致谢（导师/课题组/合作单位/家人/基金号）+ 发表文章列表（作者、题目、期刊、IF、状态）
- **常见遗漏**：基金号忘写；文章状态不标；合作单位漏掉；共同作者不标
- **追问**：
  - 致谢名单有没有漏人？（合作单位、动物房、病理平台……）
  - 发表文章——几篇一作？几篇共一？IF 分别多少？有没有在投的？
  - 基金号确认了吗？

### 板块：结束页

- **必备要素**："谢谢大家"或"敬请各位老师批评指正" + 联系方式（可选）
- **常见遗漏**：忘记放联系方式
- **追问**：
  - 要不要放邮箱或微信二维码？

### 板块：文献汇报（自问分支）

> **触发条件**：用户说"做文献汇报PPT / 讲一篇论文 / 文献汇报这篇 / 帮我讲一下这篇 / journal club / literature review / present this paper"，并提供了 PDF 或论文信息。
> **区别于答辩分支**：这些问题的回答者不是用户，是 LLM 自己。LLM 读取论文后逐项自问自答，从论文中提取答案填入设计表。用户只负责最后的确认，不参与逐板块询问。

#### 自问流程

```
用户提供论文（PDF / 链接 / 文字）
  → ① LLM 读取全文（PDF 用 skill_pdf_exec，网页用 web_fetch）
  → ② 图提取：PyMuPDF (fitz) 渲染 PDF 每页为高清 PNG（300 DPI）→ 按页面扫描大尺寸 Figure 区域
  → ③ LLM 语义阅读识别每个 Figure 的 panel 布局（a/b/c/d…）→ 按 panel 裁切为独立图片
  → ④ 裁切后的图片存入 slides/imgs/，按 Fig编号-panel 命名
  → ⑤ LLM 按以下板块逐项自问自答，设计表中直接引用裁切好的图片路径
  → ⑥ 汇总输出 PPT 设计表
  → ⑦ 用户审核确认 → 锁定 → 生成
```

> **图提取规则**：
> - 使用 PyMuPDF (`fitz`) 渲染整页（300 DPI），`pip install PyMuPDF` 即装即用，无系统依赖
> - 扫描页面内大尺寸图块区域 → 根据 LLM 语义阅读结果（该 Figure 含几个 panel、每个 panel 描述什么）裁切
> - 裁切后命名规范：`Fig2_a.jpg`、`Fig2_b.jpg`……便于设计表直接引用
> - 如果自动裁切失败或 panel 边界不清晰，保留整页截图 + 标注 panel 区域 → 发用户确认
> - 全部图片准备完毕后才进入设计表阶段

#### Paper Metadata

- **Self-ask**:
  - What is the full title of this paper?
  - Authors, corresponding author, affiliations?
  - Journal, impact factor, publication year?
  - Article type? (original research / review / case report / letter)
- **→ Fill into**: cover slide and TOC

#### Background & Rationale

- **Self-ask**:
  - What is the broad field? One-sentence summary.
  - What is the core problem or unmet need in this field?
  - What has prior work solved, and what gap remains?
  - What is this paper's specific entry point? Why did the authors do this study?
- **Recommended pages**: 2–3, progressive (field → problem → gap → this paper's rationale)
- **Common layouts**: L3 single-column text / L4 side-by-side comparison

#### Methods Overview

- **Self-ask**:
  - What is the overall experimental design? (clinical / animal / cellular / molecular…)
  - Which techniques are key? Routine vs. novel to this paper?
  - Grouping scheme? Sample sizes (n)?
  - Statistical methods?
- **Recommended pages**: 1–2
- **Common layouts**: L12 flowchart / L10 three-column cards / L7 main+sidebar

#### Key Results

- **Self-ask**:
  - How many main figures? Which are supplementary?
  - How many panels per main figure (a/b/c/d…)?
  - One-sentence takeaway per figure?
  - Which panels can share a slide (e.g., a+b on one slide)? Which need their own page?
  - Logical flow between figures? (parallel validation? progressive build?)
- **Recommended pages**: 1 data slide per main figure, 1 summary slide per 2–4 figures
- **Common layouts**: L5 full-frame image / L6 4-panel grid / L16 mixed text+figure / L9 summary

#### Deep Interrogation: Per-Panel Analysis

> **In this phase, LLM must answer WHY, not just WHAT.** For each main figure, before designing the slide, go one level deeper.

- **Self-ask (per figure, per panel)**:
  - **Panel a**: What experiment? What hypothesis does it test? What control is used? What does the data actually show?
  - **Panel b/c/d…**: Same as above, plus: how does this panel build on or complement panel a?
  - **Figure narrative**: Why is this figure placed here in the paper? What question does it answer that the previous figure left open? What question does it raise for the next figure?
  - **Controls check**: Are positive/negative controls present and adequate? Any missing controls that weaken the claim?
  - **Data quality**: n numbers? Error bars? Statistical tests? Any cherry-picked representative images?
- **Output**: For each figure, produce a 2-3 sentence "narrative bridge" that connects it to the surrounding figures. This narrative bridge becomes the slide's key conclusion text.
- **➜ This deep reading directly populates the design table's "内容概要" column and determines which panels share a slide.**

#### Discussion & Novelty

- **Self-ask**:
  - What is the core finding? How does it differ from prior work?
  - What novelty claims do the authors make?
  - What are the limitations? (author-stated + your own assessment)
  - Any over-interpretation of results?
- **Recommended pages**: 1–2
- **Common layouts**: L4 side-by-side (novelty vs. limitations) / L3 single-column text

#### Critical Appraisal

- **Self-ask**:
  - What is the significance of this paper for the field / for the user?
  - What methodological takeaways are worth noting?
  - How does it relate to the user's own research? (If user hasn't provided background, leave blank or mark "待用户补充")
- **Recommended pages**: 1
- **Common layouts**: L3 single-column text

#### Literature Review Slide Outline

| Page | Section | Content |
|------|---------|---------|
| 1 | Cover | Paper title + presenter + date + journal info |
| 2 | TOC | Background → Methods → Results → Discussion → Appraisal |
| 3–4 | Background | Field → problem → this paper's rationale |
| 5–6 | Methods | Experimental design + key techniques |
| 7–N | Results | Per-figure slides + summary slides |
| N+1 | Discussion & Novelty | Core findings + novelty + limitations |
| N+2 | Critical Appraisal | Significance + methodological takeaways |
| N+3 | Closing | Thank you + references
